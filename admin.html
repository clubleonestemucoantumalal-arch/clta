Publicar los cambios

Sirve para cualquier hosting. Descargas los archivos con los cambios y los subes a la carpeta data/ del sitio. Es el mismo gesto de siempre: arrastrar y soltar.
1
Descarga los archivos Se guardan en tu carpeta de Descargas.
2
Súbelos al sitio Reemplaza los archivos dentro de la carpeta data/.
En Netlify: entra a tu sitio → Deploys → arrastra la carpeta completa del proyecto (ya con los archivos nuevos adentro).
Por FTP: sube los archivos a public_html/data/.
3
Listo Los cambios se ven al instante. Si no aparecen, recarga con Ctrl + F5.
Publicación en un clic. Si el sitio está en GitHub (con Netlify, Vercel o GitHub Pages conectados), el panel sube los cambios solo y la web se actualiza en un par de minutos.
GitHub → Settings → Developer settings → Fine-grained tokens, con permiso Contents: Read and write sobre este repositorio.
Guarda el token solo en un computador de confianza: queda en este navegador. Si es un equipo compartido, deja el interruptor apagado y pégalo cada vez.
